# Яндекс Метрика

Счётчик **113078891** подключён один раз в корневом `src/app/layout.jsx` через `YandexMetrika` внутри `Suspense`. Переменные окружения для включения счётчика не нужны; прежний `NEXT_PUBLIC_YM_ID` больше не используется.

`next/script` загружает `https://mc.yandex.ru/metrika/tag.js?id=113078891` с `afterInteractive`. Очередь `ym` и одноразовая инициализация находятся в `src/lib/yandexMetrika.js`: переходы до загрузки скрипта не теряются. Сохранены ssr, webvisor, clickmap, ecommerce: dataLayer, referrer, url, accurateTrackBounce, trackLinks. Дополнительно включён defer: true, чтобы первый просмотр не дублировался автоматическим hit.

`usePathname` + `useSearchParams` вызывают `trackMetrikaPage` при первом открытии, изменении пути или query и при переходах назад/вперёд. Соседние одинаковые маршруты отсекаются; возвращение на ранее посещённый маршрут учитывается. Hash-переходы внутри страницы не создают просмотр.

## Данные и Вебвизор

- В hit/init передаются только известные публичные пути. Query и hash не передаются; изменение query всё равно создаёт просмотр очищенного URL. Неизвестные пути записываются как `/404`.
- Внешний referrer ограничен origin; внутренний — известным публичным путём. Заголовки страниц берутся из статических метаданных приложения.
- Все input общей LeadForm помечены ym-disable-keys, сама форма — ym-hide-content. Это распространяется на обе страницы и модальные формы предметов, включая поля с автозаполнением.
- Имена, телефоны, email, значения полей и тело API-заявки не передаются в цели или dataLayer. Существующие цели передают только фиксированные категории курса/направления.
- Webvisor, clickmap и trackLinks включены. Метрики поведения вне защищённых форм продолжают работать.
- Не добавляйте контактные данные в URL, dataLayer, названия страниц или параметры целей. Для новых форм также используйте классы защиты Яндекса.
