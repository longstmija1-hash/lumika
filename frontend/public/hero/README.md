# Hero artwork

`luma-mascots.webp` contains two transparent mascot poses in a single sprite sheet. Only ReferenceHero uses this asset. The original PNG remains in the local generated_images folder. The delivery asset is WebP, quality 92 with full alpha quality (241 KB).

Created with the built-in image_gen tool using the two user-provided website references. The two poses are displayed with CSS cropping; the rest of each hero is live HTML/CSS/SVG.

Prompt:
> Extract/recreate the two cute 3D purple and mint-green chameleon mascots from the two attached Lumika website references. Output a single wide transparent PNG sprite sheet with TWO characters separated by generous empty space: LEFT the standing chameleon with curled tail to the left, big glossy eyes, facing right from programming page. RIGHT the same chameleon reading an open green book sitting on two stacked mint and purple books from school page. Match the screenshot identity and polished claylike 3D rendering as closely as possible. FULL bodies, no cropping. True transparent alpha background. No words, no bubbles, no panels, no extra decorations. Each character occupies exactly one half of the wide canvas, equal visual height, centered in its half. This is an isolated production website asset.
