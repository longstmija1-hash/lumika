# ЛЮМИКА — обновлённый сайт

Главная страница переработана в существующем Next.js-проекте. Новых runtime-зависимостей нет.

## Запуск

Из папки `frontend`:

```sh
npm ci
npm run dev
```

Для production: `npm run build`, затем `npm start`.

## Заявки

Скопируйте `.env.example` в `.env.local` и укажите `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`. Секреты остаются на сервере. Форма использует существующий `/api/leads`; выбранное направление передаётся в поле `program`. Если настроен `NEXT_PUBLIC_API_URL`, используется существующий внешний API.

Реальные Telegram-сообщения в ходе проверки не отправлялись. Проверка формы использует перехват запроса в браузере: валидация, ответ с ошибкой, повторная отправка и успешный ответ.

## Что изменено

- Новый первый экран с интерактивными примерами Scratch, JavaScript и Go.
- Три программы, локальный подбор по возрасту, опыту и интересам.
- Процесс занятий, учебные примеры, информация о преподавателе, FAQ.
- Адаптивное меню, клавиатурное управление, focus-состояния и reduced-motion.
- Доступные подписи полей, явное согласие и состояния отправки формы.
- Убраны с главной таймеры, искусственный дефицит и неподтверждённые отзывы.
- Шрифты хранятся локально; лицензии рядом с ними в `src/app/fonts`.

Примеры обозначены как учебные, возрастные интервалы — как ориентиры. Стоимость не выдумана: её предлагается уточнить при знакомстве. Старые страницы предметов и обработчик Telegram сохранены.

## Два направления ЛЮМИКИ

Главная `/` сохраняет IT-лендинг. Новая `/school` — школьные предметы, ОГЭ и ЕГЭ. Общий переключатель использует обычные ссылки и плавное появление страницы; reduced-motion отключает анимацию.

Источники школьного содержания: предоставленный репозиторий https://github.com/longstmija1-hash/paralaxxx — данные предметов, преподавателя, форматов и пакетов занятий. Неподтверждённые отзывы и обещания баллов не перенесены.

Подбор учитывает предмет, класс и цель. Стоимость берётся из существующего lessonPackages.js. Заявка передаёт предмет, класс, цель, количество занятий и тариф в существующий обработчик Telegram. Секреты и backend не менялись.

Проверка: `qa/school-check.cjs`, переменные PLAYWRIGHT_MODULE, CHROME_PATH и QA_BASE_URL (по умолчанию http://127.0.0.1:3001). Проверяет оба направления, интерактивный урок, подбор, тариф, валидацию и данные заявки с перехватом API, мобильное меню и ширины 320–1920 px. Реальные заявки не отправляются.


## Фиксированные IT-курсы

На первом экране IT добавлен переход к школьным предметам. Новый блок #it-pricing показывает утверждённые владельцем вводные курсы: Scratch — 16 × 1 260 ₽ = 20 160 ₽; JavaScript и Go — каждый 32 × 1 188 ₽ = 38 016 ₽. Занятия индивидуальные по 45 минут. Данные отдельно в src/data/itCoursePricing.js, чтобы школьные тарифы не меняли стоимость IT автоматически. Форма включает полную стоимость и состав курса.

Production-сборка и qa/it-pricing-check.cjs успешно пройдены: переход между направлениями, три расчёта, выбор в форме, данные заявки с перехватом API и ширины 320–1920 px.

## Программа, знакомство и короткая форма

Добавлена программа IT-курсов из трёх этапов с диапазонами занятий и результатом каждого этапа. В карточке Данила используется предоставленное фото `/intro-portrait.jpg`. Пробное занятие — бесплатное знакомство 20–30 минут, без подготовки. Эти условия указаны в записи и FAQ обоих направлений.

Обязательны имя, телефон и согласие. Email спрятан в раскрывающийся блок и необязателен; заполненный email проверяется. После заявки указано, что команда свяжется по телефону.

## События воронки

Инструментирование: `src/lib/funnelAnalytics.js`, `FunnelAnalytics.jsx`, `LeadForm.jsx`. Используются существующая Vercel Web Analytics и, при NEXT_PUBLIC_YM_ID, Яндекс Метрика. Для получения отчётов нужно включить аналитику проекта на хостинге; доступность custom events зависит от настроек/тарифа провайдера. Для Метрики задайте ID при сборке и создайте JavaScript-цели с идентификаторами ниже. Локальная проверка не подтверждает сбор событий в внешнем кабинете.

- `pricing_view`: видимость минимум 20% блока расчёта, один раз за посещение страницы.
- `course_select`: явный выбор направления в программах, ценах или форме.
- `lead_start`: первое изменение формы, один раз до успешной отправки.
- `lead_success`: только успешный ответ API, ошибка и валидация не считаются заявкой.

Параметры строго ограничены `direction` (it/school) и `course` (одно из известных направлений/undecided). Имя, телефон, email, свободный текст и URL в custom events не передаются. Для отладки доступно браузерное событие `lumika:funnel`; оно не хранит данные. Сбой аналитики не блокирует форму.

Воронка для анализа: просмотр цен → выбор курса → начало формы → успешная заявка. Считать по пользователям/сессиям, а не делить сырые суммы кликов: один посетитель может менять курс несколько раз. Подбор курса может происходить до просмотра цены.

Проверка: `qa/funnel-check.cjs`. Перехват API, ошибка/повторная отправка, email, события и отсутствие контактов в них, клавиатурные вкладки и адаптивность.

Проверка 23.09.2026: production-сборка успешна; сценарии qa/funnel-check.cjs пройдены на 320, 390, 768, 1024, 1440 px. Реальные заявки не отправлялись.
